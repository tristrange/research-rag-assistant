API reference

Its complete, current schema is available as OpenAPI JSON.

GET /

Open the browser interface.

GET /documents

List the filenames of indexed papers.

GET /status

Check database/schema access, Ollama connectivity, and installed answer and embedding models. Returns diagnostic results without inference, model downloads, or index changes.

POST /query

Ask a question and receive an answer with retrieved passages. Send JSON with a question, and optionally a document or scope.

curl -X POST http://127.0.0.1:8000/query \
  -H 'Content-Type: application/json' \
  -d '{"question":"What were the main findings?"}'
